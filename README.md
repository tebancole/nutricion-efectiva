# Nutrición Efectiva

Proyecto inicial en Next.js para la página web de Nutrición Efectiva.

## Cómo correrlo

```bash
npm install
npm run dev
```

Luego abre:

```bash
http://localhost:3000
```

## Pendientes

1. Cambiar el número de WhatsApp en `src/app/page.tsx`.
2. Conectar el formulario a Formspree, EmailJS, Resend o un backend propio.
3. Ajustar textos finales de servicios y biografía.
